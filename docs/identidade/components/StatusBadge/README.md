# StatusBadge

Selo de estado (settings/status-badge.tsx): raio radius-sm, padding 2 × 6, 12 px peso 500.

- Tons: success, warning e danger sobre o respectivo -soft; neutro em bg-surface-hover com text-muted. Não há selo azul (phase 18): "Trabalhando", "Na fila", "Cancelada", "Desfeita" e "Em uso" são neutros.
- O selo sempre leva texto; a cor nunca é a única informação. "Trabalhando" ganha o ponto pulsante.
